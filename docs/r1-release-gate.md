# R1 출시 게이트 (Subok / Iron Line ALPHA R1.0)

작성: 2026-07-04. 북극성: **"전쟁에서 혼자가 아니다"** — 탑다운 2D 전장에서 AI 분대와 함께 싸우는 감각.
이 문서의 목적: "완성"의 정의를 고정해서, 새 아이디어가 생겨도 게이트 밖이면 R2 백로그로 보낸다. **게이트를 넓히는 수정은 금지. 좁히는 것만 허용.**

## 범위 확정 (이미 결정된 것 — 재논의 금지)

R1에 포함:
- 오프라인 15v15 (섬멸전/점령전), 온라인 방 기반 멀티 (기존 완성분)
- 흐름: 로딩 → 메인(닉네임/게스트) → 로비&세력 → 게임세팅 → 전투
- 병과 3종 + 무기 12종 (이미지 슬롯 UI), 전차/험비/드론
- AI 분대 전투 (교전 거리·제압·엎드림 튜닝 포함)

R1에서 제외 (R2+ 백로그):
- 계정/비밀번호 로그인 (게스트+닉네임으로 충분)
- 창작마당/UGC (?assetPack= 로딩이 이미 기반, UI만 R2에서)
- 새 맵, 헬기, 신규 차량
- 보병/험비 스프라이트 (전차 슬롯 패턴 검증 후)
- AI 엔진 대수술 (버그 단위 점진 개선만)

## 출시 게이트 체크리스트

### G1. 기술 (자동 검증)
- [ ] `npm run check` 통과 (문법/중복/헬스/에셋)
- [ ] `npm run check:online` 통과 (4v4 8인 ready까지)
- [ ] `node tools/check-battlefield-tempo.cjs` 2회: deaths/min 6~12, survival p50 20~30초, prone ratio > 0.10
- [ ] 교전 유지 거리 수정 검증 (2026-07-04 적용분 — 최우선 미결)

### G2. 체감 (수동 플레이, 각 15분)
- [ ] PC: 메인→전투→사망→재시작 루프에 막힘 없음
- [ ] 모바일(실기기): 시야 확보 상태로 이동·조준 가능 ← 지시서: docs/mobile-fov-blueprint.md
- [ ] 온라인 2인: 방 생성→입장→전투→결과까지 끊김 없음
- [ ] "AI 분대가 옆에서 싸운다"가 느껴지는가 (북극성 자가 테스트)

### G3. 표면 품질
- [ ] 로비/세팅 화면 짤림 없음 (PC/모바일 각 1회 확인)
- [ ] 버전 표기 ALPHA R1.0 일관
- [ ] 무기 일러스트: 플레이스홀더 그대로 출시 OK (교체는 파일 덮어쓰기만)
- [ ] 전차 스프라이트: 켜든(앵커 튜닝 후) 끄든(벡터) 한쪽으로 확정

### G4. 배포
- [ ] 서버 상시 구동 방법 확정 (현 static-server + ws)
- [ ] 미커밋 변경 전부 커밋 (2026-07-03~04 작업분 포함)
- [ ] 첫 외부 테스터 3명에게 링크 전달 ← **이게 출시다**

## 규칙

1. 게이트에 없는 작업이 하고 싶어지면 → 이 문서 하단 "R2 백로그"에 한 줄 적고 원래 작업으로 복귀.
2. 세션마다 게이트 항목 하나를 닫는 것을 우선. 새 시스템 착수는 게이트 전부 닫힌 뒤.
3. G4까지 닫히면 그날 배포한다. "조금만 더"는 없다.

## R2 백로그 (여기에만 추가)

- 계정 시스템, 팩 선택 UI(창작마당 기반), 새 맵, 헬기, 보병 스프라이트
- 커맨더 재공세 규칙(D3), 차량 선제킬 완화 — 게이트 G1 통과에 불필요하면 R2로
- 휴먼 지휘관 롤: 관전 카메라+전술지도+command-radio를 묶는 UI 작업 (기반 전부 존재, 8인방 지휘관 슬롯 1개)
- 지휘관 명령 무전 노출 (R1 후보로 승격 가능 — 최소 비용으로 "혼자가 아니다" 체감) → 구현 지시서: docs/commander-presence-blueprint.md (재공세 D3 포함)
- AI 행동 계측("눈") 구현 지시서: docs/ai-eyes-blueprint.md → GPT/Codex에 위임 가능
- 4번키 회복킷 (R1.5 소형), 위생병 병과, 부상병 소생/후송 (playerDowned 상태 확장)
- 폭발·사운드·잔해: docs/explosion-impact-plan.md ①~④
- 맵 파이프라인 (2026-07-04 결정): 에디터 엔진화 대신 **맵 스키마 고정** → AI가 데이터로 초안(교전거리 예산: 시야선 500~700/엄폐 간격 30~60/첫 접촉 25~35초) → 기존 에디터로 눈 튜닝 → 템포 프로브로 검증. 1호 "철선"(가로 진격전, A-B-C 일자, 3레인) → 2호 시가전. 창작마당 확장은 맵 파일 포맷이 담당
- 플레이스토어 (2026-07-04 결정): R1 웹 배포 → R1.5 같은 URL을 TWA로 스토어 등록. 선행: HTTPS/WSS 호스팅, ws 메시지 크기·빈도 제한, admin 명령 서버측 가드, 개인정보처리방침 1장(수집=닉네임뿐), 개발자 계정 $25. 광고 SDK는 넣지 않음
- 수익화 순서: 게임 내 광고판=재미 요소(에셋 슬롯으로 이미지 교체, 지금 가능) → 스킨 상점(스킨 엔진이 기반, 리텐션 확인 후) → 광고 네트워크(트래픽 생긴 뒤)
