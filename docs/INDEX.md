# Docs Index

Iron Line 2D Tank Prototype의 현재 구조, 운영 설계, AI 설계, 코드 관리 규칙을 모아둔다.

## System Docs

- [Code Structure Rules](code-structure-rules.md): 큰 파일에 코드가 계속 쌓이지 않도록 하는 모듈 분리 규칙과 `npm run check` 코드 건강도 예산.
- [Online Operations Center](online-operations-center.md): 관리자 운영센터, AI 연구실, 백업 JSON, 온라인 대비 방/슬롯/명령 패킷 상태 구조.
- [AI and Combat Architecture](ai-and-combat-architecture.md): 전차 AI, 보병 AI, 병과/장비, 무기/전투 시스템의 현재 구조와 다음 확장 순서.
- [AI Doctrine V2](ai-doctrine-v2.md): 분대 지휘요청, 지원가 자산 배정, 공병/대전차/드론 교리 확장을 위한 2차 AI 설계 기준.
- [Production Prep](production-prep.md): 로컬 실행, 문법 검사, 시작 화면/플레이 검증 기준.
