# 수복 스토리 문서

`수복`의 세계관, 인물, 캠페인 흐름을 모아두는 폴더다. 이 폴더는 스토리모드, 일러스트, 에셋 계약을 잡기 전의 기준 위치로 쓴다.

## 바로 열기

- [세계관 보드](world-board.html): 눈으로 한눈에 보고, 직접 메모를 수정하고, 브라우저에 저장하는 HTML 보드.
- [세계관 마인드맵](world-mindmap.html): 스토리와 세계관의 관계를 그림처럼 한 장으로 보는 HTML 마인드맵.
- [세계관 바이블](world-bible.md): 현재 정식 설정 원본. AI와 작업할 때 기준으로 삼는 문서.

## 사용 기준

- 빠르게 보고 고칠 때는 `world-board.html`을 연다.
- 정식 설정으로 확정할 때는 `world-bible.md`에 반영한다.
- HTML 보드의 저장은 브라우저 `localStorage`에 남는다. 파일로 영구 보관하려면 보드에서 Markdown 또는 JSON으로 내보낸다.
