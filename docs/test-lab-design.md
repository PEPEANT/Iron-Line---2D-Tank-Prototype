# 테스트랩 설계

결론: 관리자는 관제탑 역할에 집중하고, 실험은 `index.html?testLab=hub`에서 들어가는 독립 시험장 안에서 진행한다.

## 목적

테스트랩은 실제 게임 루프, 렌더러, 물리, 인공지능, 무기, 세력 비주얼을 재사용한다. 그래야 보병, 전차, 험비 스킨과 밸런스 감각이 정적 목업이 아니라 실제 전장 기준으로 검증된다.

## 현재 진입점

- `index.html?testLab=hub`: 모든 실험 모드를 고르는 통합 런처.
- `index.html?testLab=unit`: 보병, 전차, 험비 투입과 교전 상태 확인.
- `index.html?testLab=drone`: 드론 배치, 지붕 고정, 탐지 흐름 확인.
- `index.html?testLab=balance`: 철갑탄, 고폭탄, 직격, 장갑 방향 피격 로그 확인.
- `index.html?testLab=audio`: 로컬 음원 재생, 정지, 반복, 볼륨 확인.
- `index.html?testLab=skin`: 실제 게임 렌더러로 세력별 보병, 전차, 험비 미리보기.
- `index.html?testLab=objects`: 건물, 벽, 장식류 전시와 배치 설정창.
- `editor.html`: 전체 맵 에디터.
- `admin.html`: 분리형 관리자 관전 및 운영 화면.

## 관리자 역할

관리자 화면은 실험을 실행하고 기록하는 곳이지, 실험장을 덮는 곳이 아니다.

- 통합 테스트랩 바로가기를 가장 크게 둔다.
- 개별 테스트랩 버튼은 디버그용 빠른 진입으로 유지한다.
- 실험장 콘솔 헤더의 `관리자 패널` 버튼으로 분리형 관리자 화면으로 이동할 수 있다.
- 맵 검증, 백업, 실험 노트는 바로가기 주변에 둔다.
- 실험 UI 본문은 `hud-admin-ui.js`에 더 쌓지 않고 전용 모듈로 분리한다.

## 실험 모드

현재 구현:

- `hub`: 통합 런처와 독립 시험장 요약.
- `unit`: `F1`, `F2`, `F3`으로 보병, 전차, 험비 투입 및 체력 행 확인.
- `drone`: 정찰 드론, 지붕 배치, 배터리와 목표 좌표 확인.
- `balance`: 철갑탄/고폭탄 기준값과 최근 장갑 피격 로그 확인.
- `audio`: 로컬 음원 불러오기, 재생, 정지, 반복, 진행률, 볼륨 확인.
- `skin`: 실제 렌더러 미리보기와 청팀/홍팀 임시 적용 테스트.
- `objects`: 카탈로그 선택, 배치 설정창, 시험장 배치, 배치 삭제.

## UI 규칙

현재 규칙:

- 화면에 보이는 테스트랩 표기는 한글 우선이다. 내부 라우트 식별자는 코드값으로 유지할 수 있다.
- 오른쪽 콘솔은 작은 데스크톱 폭에서 자동 접힘 상태로 시작해 전장을 가리지 않는다.
- 스킨 미리보기는 실제 게임 렌더러를 사용한다. 최종 확인용으로 가짜 CSS 유닛 그림을 추가하지 않는다.
- 오브젝트 카드는 바로 맵에 쓰지 않고 배치 설정창을 먼저 연다.
- 흰색과 회색 사이의 독립 시험장 바닥을 사용해 실전 맵과 시각적으로 분리한다.
- 오브젝트 테스트랩의 렌더, 배치 설정창, 직접 배치 로직은 `src/systems/test-lab-objects.js`에 둔다.

## 독립 시험장

현재 구현:

- 테스트랩 진입 시 `src/data/test-lab-map.js`에서 생성한 `test-lab-proving-ground`로 전환한다.
- 실험장 이름은 `독립 실험장`이다.
- 바닥은 밝은 흰색/회색 산업 팔레트를 사용한다.
- 건물, 방벽, 바리케이드, 나무, 덤불, 잔해를 한 곳에 모은 오브젝트 전시장이 있다.
- 유닛, 밸런스, 드론, 스킨 확인용 교전 구역도 같은 독립 맵 안에 유지한다.

## 다음 확장

- 스킨 연구실에 가져오기/내보내기와 저장 프리셋을 붙인다.
- 음원 테스트랩에 기본 효과음/배경음 샘플 목록을 붙인다.
- 오브젝트 배치가 안정되면 맵 에디터로 넘기는 흐름을 만든다.
- 새 실험 모드는 주소, 한글 표시명, 관리자 허브 설명을 함께 추가한다.

## 데이터 방향

유닛 디자인은 먼저 데이터 카탈로그에 넣고, 테스트랩에서 검증한 뒤, 일반 렌더링에 연결한다.

권장 형태:

```js
{
  factionId: "usa",
  infantry: {},
  tank: {},
  humvee: {},
  drone: {},
  ui: {}
}
```

미군과 중국군 샘플부터 시작한다. 미리보기와 가져오기/내보내기 형태가 안정된 뒤 다른 세력으로 확장한다.

## 제약

- 테스트랩 UI를 만들기 위해 실전 밸런스를 바꾸지 않는다.
- 새 관리자/테스트 기능은 기존 대형 파일에 더 쌓지 않는다.
- `hud-admin-ui.js`, `renderer.js`는 다음 기능 추가 전에 분리 후보로 본다.
- `test-lab-ui.js`에는 공통 패널 흐름만 남기고, 새 실험 모드는 전용 모듈로 붙인다.
