게임, 실험장, 에디터, 작업중 문서, 완료 기준을 한 곳에서 들어갑니다. 이 페이지는 개발자용 임시 허브입니다.

플레이

게임 시작 메인 메뉴로 진입해 오프라인/온라인 플레이 스토리 모드 메인 메뉴 → 스토리 버튼. 챕터 카드 8장, 클리어하면 다음 챕터 해금 소개 홈페이지 세계관, 세력 스킨, 패치 소식

개발 · 실험

샌드박스 실험장 도감에서 유닛/오브젝트 카드를 골라 맵 클릭으로 즉시 배치. 새 그래픽 에셋 확인용 맵 에디터 맵 구조, 거점, 오브젝트 편집 관리자 관제 관전 카메라, 방 운영, 실험 노트 리플레이 뷰어 기록된 전투 재생과 분석 메인메뉴 레이아웃 튜너 타이틀 화면 배치 실시간 조정 보병 파츠 리그 랩 v2 폐기/참고용 리그 실험실. 보병 파츠, 핀, 포즈, 굽기 결과 확인 infantry-rig-lab.html 에셋 컷팅 랩 원본 통합 PNG에서 필요한 부위를 직접 박스로 잘라 PNG와 JSON으로 저장 asset-crop-lab.html 보병/차량 컷 정리 v2 확정된 보병·차량 컷, 액션점 판정, 본편 적용 후보를 한눈에 확인 cut-review/v2-20260709
